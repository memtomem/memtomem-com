처음부터 모든 기능을 설정할 필요는 없습니다. 지금 필요한 결과를 하나 고르고, 실제로 동작하는지 확인한 뒤 다음 기능을 추가하세요.

## 여기서 시작하세요

| 하고 싶은 일 | 시작 문서 | 완료 기준 |
|---|---|---|
| 기억 저장과 검색이 되는지 확인 | [빠른 시작](/ko/guides/quickstart/) | 방금 추가한 기억이 `mm search` 결과에 표시됨 |
| 새 AI 세션에서 이전 결정을 다시 찾기 | [세션을 넘나드는 기억](/ko/guides/memory-persistence/) | 새 세션에서 저장한 이유와 출처까지 확인 |
| Claude Code·Codex·다른 MCP 클라이언트 연결 | [AI 클라이언트 연결](/ko/guides/connect-ai-client/) | 클라이언트에서 `mem_status` 호출 성공 |
| 기존 노트·문서·코드·AI 도구 기억 검색 | [기존 자료 색인·가져오기](/ko/guides/index-and-import/) | 알고 있는 문구가 출처 경로와 함께 검색됨 |
| 응답 압축이나 관련 기억 자동 제시 추가 | [MCP 서버에 STM 추가](/ko/guides/stm-first-proxy/) | 프록시 호출이 `mms stats --source mcp`에 기록됨 |
| 개인·에이전트·공유 기억 분리 | [멀티 에이전트 협업](/ko/ltm/multi-agent/) | 한 에이전트가 검토한 기억을 공유하고 다른 에이전트가 검색 |
| 여러 실행 환경의 스킬·명령 관리 | [Context Gateway](/ko/ltm/context-gateway/) | Store 기준본을 미리 확인하고 선택한 실행 환경에 Push |
| 로컬 저장과 외부 전송 범위 확인 | [로컬 우선 · 정보 보호](/ko/guides/privacy/) | 켠 연동 가운데 어떤 것이 외부로 데이터를 보내는지 파악 |
| 기존 설치 진단·운영 | [문제 해결](/ko/guides/troubleshooting/)과 [운영 및 API](/ko/ltm/operations/) | 상태 점검 통과 또는 구체적인 복구 단계 확인 |

## LTM과 STM 중 무엇부터 쓸까?

먼저 **LTM**(`memtomem`)으로 시작하세요. LTM은 기억을 오래 보관하고 필요할 때 검색합니다. MCP 응답 압축, 캐시, 관련 기억 자동 제시가 필요해졌을 때만 **STM**(`memtomem-stm`)을 추가합니다.

| 필요한 기능 | LTM | STM |
|---|---:|---:|
| 세션을 넘어 결정 보관 | 필요 | 불필요 |
| 노트·문서·코드 검색 | 필요 | 불필요 |
| 여러 AI 클라이언트에서 한 저장소 사용 | 필요 | 불필요 |
| MCP 도구 응답 압축 | 지원하지 않음 | 필요 |
| 프록시 호출에 관련 LTM 기억 추가 | 기억 제공 | 자동 제시 수행 |
| 첫 설정에 필수 | 예 | 아니요 |

STM은 LTM을 대체하지 않으며, 프록시를 거친 응답을 모두 장기 기억에 쓰지도 않습니다. 두 패키지는 따로 실행되며 관련 기억 자동 제시를 켰을 때 MCP로 통신합니다.

## 자동으로 되지 않는 일

플러그인을 설치하거나 MCP 서버를 등록해도 다음 작업은 자동으로 실행되지 않습니다.

- 프로젝트 전체 색인
- 모든 파일의 백그라운드 감시
- Claude Code·Codex·Gemini/Antigravity 기억 전체 가져오기
- 대화 전체나 모든 도구 응답 저장
- 서로 다른 컴퓨터의 데이터베이스 동기화

이 결과가 필요할 때는 색인, 가져오기, 저장, 동기화 작업을 명시적으로 실행하세요.

## 첫 주 권장 순서

1. MCP 클라이언트 없이 [빠른 시작](/ko/guides/quickstart/)을 완료합니다.
2. AI 클라이언트 하나를 연결하고 `mem_status`를 확인합니다.
3. 검증된 결정 하나를 저장하고 새 세션에서 다시 찾습니다.
4. 민감 정보가 없는 작은 문서 폴더 하나를 색인하고 출처가 표시되는지 확인합니다.
5. 응답을 중계할 MCP 서버를 정할 수 있을 때만 STM을 추가합니다.

항상 적용해야 하는 프로젝트 규칙은 `CLAUDE.md`, `AGENTS.md` 같은 실행 환경 지침 파일에 둡니다. 나중에 다시 찾을 결정, 조사 결과, 반복 절차는 memtomem에 저장하세요.
