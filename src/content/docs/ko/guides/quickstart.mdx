이 가이드는 먼저 하나의 기본 흐름을 성공시키는 데 집중합니다. LTM 서버를 설치하고, MCP 클라이언트에 등록하고, 폴더를 인덱싱한 뒤 에이전트가 검색하게 만듭니다. STM은 선택 사항이며 기본 기억 루프가 동작한 뒤 추가하면 됩니다.

## 1. 설치

```bash
uv tool install 'memtomem[all]'       # 또는: pipx install 'memtomem[all]'
mm --version
```

`[all]`은 Web UI, 로컬 ONNX 임베딩, 코드 청킹, 한국어 토크나이저, Ollama / OpenAI 프로바이더 클라이언트를 포함합니다. 더 작은 BM25 전용 설치는 [설치](/ko/guides/installation/#ltm-서버-memtomem)를 참고하세요.

설치 직후 `mm --version`이 예상보다 오래된 버전을 출력하면 패키지 메타데이터를 새로고침하면서 업그레이드하세요:

```bash
uv tool install 'memtomem[all]' --upgrade
```

## 2. 초기 설정

```bash
mm init
```

마법사는 프리셋 피커로 시작합니다:

| 프리셋 | 적합한 상황 | 동작 |
|---|---|---|
| Minimal | 첫 스모크 테스트, 최소 설치 | BM25 키워드 검색만 사용 |
| English | 영어 프로젝트 대부분 | 로컬 ONNX 임베딩 + 영어 리랭커 |
| Korean | 한국어 또는 다국어 노트 | 다국어 임베딩, 리랭커, 한국어 토크나이저 |

스크립트나 CI에서는 다음을 사용할 수 있습니다:

```bash
mm init -y                   # minimal 프리셋, 프롬프트 없음
mm init --preset english -y  # 영어 프리셋, 프롬프트 없음
mm init --preset korean -y   # 한국어 프리셋, 프롬프트 없음
mm init --advanced           # 전체 마법사
```

설정 중 Claude Code 기억, Claude 플랜, Codex CLI 기억 같은 기존 AI 에이전트 메모리 폴더를 등록할 수 있습니다. 등록은 이후 변경 감시를 위한 것이므로, 이미 존재하는 파일은 `mm index`로 한 번 시드하세요.

## 3. 로컬 점검

에디터에 연결하기 전에 CLI가 설정과 DB를 열 수 있는지 확인합니다:

```bash
mm status
```

스토리지, 임베딩, 청크 수 요약이 보이면 정상입니다. 아직 인덱싱 전이라 청크가 0개인 것은 정상입니다.

## 5. 기억 추가와 검색

먼저 CLI로 전체 루프를 확인합니다:

```bash
mm add \
  "스테이징 배포는 docs/deploy.md의 blue-green 체크리스트를 따른다" \
  --tags "deploy,ops"
mm search "스테이징 배포 체크리스트"
```

그 다음 에이전트가 검색해야 할 노트, 문서, 코드를 인덱싱합니다:

```bash
mm index ~/notes
mm index ~/projects/my-app/docs
```

이후 MCP 클라이언트에서는 자연어로 지시하면 됩니다:

| 에이전트에 지시 | 보통 호출되는 도구 | 결과 |
|---|---|---|
| "memtomem 상태 확인" | `mem_status` | 연결 및 인덱스 요약 |
| "이 결정을 기억해줘..." | `mem_add` | 마크다운 기억으로 저장 |
| "이 docs 폴더 인덱싱해줘" | `mem_index` | 기존 파일이 검색 가능해짐 |
| "배포 체크리스트 검색" | `mem_search` | 관련 기억 스니펫 순위 목록 |

## 6. Web UI 열기

```bash
mm web --open
```

기본 Web UI는 검색, 소스, 태그, 타임라인, 설정, Context Gateway를 다루는 사용자용 화면입니다. `mm web --dev`는 대부분의 사용자가 필요로 하지 않는 유지보수용 페이지를 추가합니다.

## 선택 사항: STM은 나중에 추가

`memtomem-stm`은 능동적 기억 서피싱과 응답 압축을 위한 별도 프록시입니다. 위 LTM 흐름이 동작한 뒤 추가하세요:

```bash
uv tool install memtomem-stm
mms init --mcp claude
mms health
```

도구 응답 압축이나 자동 기억 주입이 필요해질 때 [STM 개요](/ko/stm/overview/)를 참고하세요.
